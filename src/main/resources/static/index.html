Service Order Management API

A REST API for managing clients, technicians and service orders, help desk style. Built with Spring Boot, secured with JWT and covered by automated tests.

Try it in Swagger UI View the source on GitHub

What it does

Service order lifecycle

Orders move through enforced status transitions, and finishing one requires a root cause report.

Authentication and roles

JWT access tokens, rotating refresh tokens, ADMIN and USER roles, and login rate limiting.

Audit trail

Every order records who created it and who changed it last, and concurrent edits never overwrite each other silently.

PDF reports

Download a report for any service order, and filter and paginate the list by status, priority, client, technician or title.

Order lifecycle

OPEN assign → IN_PROGRESS finish → FINISHED (or cancel from OPEN / IN_PROGRESS to CANCELED)

Main endpoints

Method and pathDescription
POST /auth/loginLog in and receive an access token and a refresh token
POST /auth/refreshExchange a refresh token for a new pair
GET /ordersList service orders with filters and pagination
POST /ordersCreate a service order for a client
PUT /orders/{id}/assign/{technicianId}Assign a technician
GET /orders/{id}/reportDownload the order report as PDF

Every endpoint except login needs a token, so the interactive docs are the best place to start.
